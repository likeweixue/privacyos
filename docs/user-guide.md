# PrivacyOS 用户手册

适用于 PrivacyOS 1.2（普通版 / 专业版）。界面支持简体中文与 English，可在任务栏/开始菜单切换。

## 0. 桌面与窗口

登录后进入 Windows 风格桌面，界面使用 Flarum 2.0 的扁平设计语言（白色表面、浅灰内容区、
1px 边框、小圆角）：

- **任务栏**：开始按钮、搜索、所有打开的窗口、通知、主题、语言、时钟与用户菜单。
- **开始菜单**：按「核心设置 / 功能 / 系统」分组，可搜索；点击图标打开一个**新窗口**。
- **桌面图标**：双击打开新窗口；窄屏上单击即可打开；右键桌面可新建文件窗口、显示桌面。
- **多窗口**：可以同时打开多个窗口，**包括多个文件管理窗口**对照目录；
  任务栏会显示「文件管理 · 1 / · 2」；窗口可拖动、右下角缩放、最小化、最大化、关闭。
- **新窗口**：文件管理窗口右上角的「新建窗口」；任务栏窗口右键菜单也支持新建/关闭。
- **显示桌面**：任务栏最右侧细条，或右键桌面选择「显示桌面」。
- **用户菜单**：系统设置、修改密码、退出登录。
- **主题/语言**：任务栏右侧托盘或开始菜单底部切换深色/浅色与中英文。
- **移动端**：窗口自动最大化，任务栏按钮切换应用；开始菜单单列/双列自适应。

## 1. 登录

1. 浏览器访问 `http://<设备IP>`。
2. 输入用户名与密码；如管理员为你启用了双重认证，会出现 6 位动态验证码输入框。
3. 连续输错密码会触发**递增延迟**（第 3 次起 3s、6s、12s……），达到阈值会临时锁定。
4. 专业版若配置了销毁策略，错误次数达到阈值会**销毁该账号数据**——请勿在公共环境尝试猜测密码。

首次登录后请立即修改密码（右上角用户菜单 → 修改密码，或 系统设置 → 账户安全）。

## 2. 仪表盘

- **系统状态**：版本、操作系统、数据库、Docker、存储、运行时间；工具菜单可清除缓存、
  查看系统信息、展开高级设置（CPU/负载/内存/进程）。
- **统计**：用户、文件、照片、影片、分享链接数量。
- **公告**：最近通知与安全提示。
- **扩展**：模块状态点、全部扩展入口、需关注的告警。
- **网络流量图**：每 5 秒刷新。
- **最近活动**：登录、文件、用户、容器等操作；管理员可跳转审计日志。

## 3. 文件管理

### 浏览与选择

- 左侧目录树按需展开；点击文件夹进入，面包屑可快速回退。
- 顶部搜索框在**当前用户空间**内按文件名搜索（最多 8 层）。
- 支持列表 / 网格 / **分栏**视图；网格视图对图片和视频显示缩略图。
- 单击选择，双击打开；`Ctrl/Cmd + 单击`多选；在网格空白处按住拖动可以**框选**；右键打开快捷菜单。
- 点击工具栏「预览边栏」打开右侧预览；选中文件后按 **空格** 可快速预览文本、图片、音视频和 PDF。
- 「批量重命名」支持添加开头、添加末尾、在指定位置插入、查找替换；应用前有预览。

### 常用操作

| 操作 | 说明 |
| --- | --- |
| 上传 | 拖拽文件到右侧区域，或点击「上传文件」；支持多选，显示总进度 |
| 新建文件夹 | 在当前目录创建 |
| 下载 | 文件直接下载；文件夹自动打包为 zip |
| 重命名 | 同目录内改名，重名会提示冲突 |
| 移动 / 复制 | 选择目标目录；移动为同盘 `rename`，跨盘自动复制后删除 |
| 压缩下载 | 选中多个文件/文件夹打包 |
| 解压 | 支持 `.zip`、`.tar`、`.tar.gz`；默认解压到同名文件夹 |
| 分享 | 生成公开链接，可设密码、有效期、最大下载次数 |
| 删除 | 移入回收站，可在保留期内恢复或彻底清空 |

### 配额

- 配额按用户设置，统计 `users/`、`photos/`、`movies/` 三个目录。
- 超出配额时上传返回 507，需要管理员调整配额或清理回收站。

### 回收站

- 保留期默认 30 天（系统设置 → 销毁/删除策略）。
- 「恢复」按原路径放回；若原路径已被占用，会自动生成不冲突的新名称。
- 「清空回收站」不可恢复。

### 管理员查看所有用户（仅普通版）

- 打开左下角「所有用户」开关后，可以浏览 `/data/users` 下的全部用户目录。
- 专业版强制关闭此能力；管理员只能看到自己的目录。

### 分享链接

- 创建后得到 `http://<IP>/s/<token>`。
- 访问者无需登录；如设置密码，需要先输入。
- 支持有效期与下载次数限制；可随时在「分享」记录中撤销。

### WebDAV

- 地址：`http://<IP>/dav/`，账号密码同 Web 登录。
- macOS Finder：前往 → 连接服务器 → `http://<IP>/dav`。
- Windows：映射网络驱动器。
- 建议先在系统设置启用 HTTPS。

## 4. 相册

### 上传与归档

- 上传照片时读取 EXIF 拍摄时间，自动保存到 `/data/photos/<用户名>/YYYY/MM/DD/`。
- 无 EXIF 时使用上传时间。
- 也可以把照片直接放入该目录，然后点击「扫描媒体库」。

### 视图

- **时间轴**：按年/月分组，按月筛选；每张照片显示缩略图。
- **相册**：手动创建相册，从照片详情或批量选择中加入。
- **地图**：带 GPS 的照片以经纬度散点展示，并列出位置；不加载外部地图瓦片，避免隐私泄露。

### 照片详情

点击照片打开侧栏，可查看拍摄时间、相机、镜头、分辨率、大小、GPS，
并下载原图、创建分享、加入相册或删除。

### 批量操作

点击「选择照片」进入多选模式，可批量加入相册或删除。

## 5. 影视中心

### 添加影片

1. 通过文件管理/SMB 把影片放到 `/data/movies/<用户名>/`（支持子目录分类）。
2. 点击「扫描媒体库」。系统会解析文件名（`S01E02`、年份、清晰度标签）并读取 ffprobe 元数据。
3. 配置 TMDB API Key 后，点击「刮削元数据」自动获取海报、简介、演员、评分。

### 浏览

- 海报墙支持搜索、类型、年份、排序（名称/最新/评分/最近添加）。
- 点击海报打开详情：简介、演员、类型、时长、分辨率、编码、字幕列表。
- 若文件存在，播放按钮可用；不存在时显示「未关联媒体文件」。

### 播放

- 浏览器原生播放器，支持 Range 拖动、音量、全屏、倍速（0.5×–2×）。
- 外挂字幕放在影片同目录，文件名与影片一致（`.srt` / `.vtt` / `.ass`）。
  SRT 会自动转换为 WebVTT 以兼容浏览器。
- MKV 等容器的兼容性取决于浏览器；如需广泛兼容，可安装 Jellyfin 应用。

### 手动编辑

未配置 TMDB 或刮削不准确时，可在详情中「编辑信息」修改标题、年份、类型、简介、标签。

## 6. Docker

- 顶部显示 Docker 版本；守护进程不可用时给出提示。
- **容器**：状态、端口、CPU/内存；支持启动/停止/重启、日志、资源占用、删除。
- **镜像**：拉取（后台任务）、删除。
- **Compose**：新建项目（粘贴 `docker-compose.yml`）、部署、停止、日志、删除。
- 容器与应用均以 root 运行面板，普通用户是否可用由「功能权限 → Docker」控制。

> Docker 需要 `docker.io` 与 `docker-compose`。DVD-1 不含这些包，
> 联网首次启动会自动补装，或手动运行 `privacyos-provision`。

## 7. 用户管理（管理员）

### 添加用户

- 用户名：3–32 位字母、数字、`_`、`-`，同时创建 Linux 与 Samba 账号。
- 初始密码至少 8 位。
- 角色：管理员 / 普通用户。
- 配额：以 GB 输入，0 表示不限。
- 功能权限：文件、相册、影视、分享、Docker、应用中心；管理员默认全部开启。

### 操作

| 操作 | 说明 |
| --- | --- |
| 编辑 | 修改显示名、角色、状态、配额、权限 |
| 重置密码 | 同时更新 Linux/Samba 密码并注销该用户全部会话 |
| 解锁 | 清除临时锁定与失败计数 |
| 用量 | 查看已用空间、配额、回收站、文件数（专业版仅本人） |
| 删除 | 普通版立即删除；专业版进入冷静期，可恢复 |

### 删除冷静期（专业版）

- 删除用户后状态变为「待删除」，默认保留 30 天。
- 「待删除用户」面板显示剩余天数，可点击「恢复」。
- 到期后后台 janitor 永久删除账号与数据。

## 8. 存储管理（管理员）

### 磁盘

- 型号、序列号、容量、类型、健康（SMART）、温度、通电时长、挂载点与使用率。
- 点击「SMART 测试」打开抽屉，可执行短/长测试并查看历史。

### 存储池

- 创建：选择 RAID 级别（0/1/5/6/10/linear）、文件系统（ext4/xfs/btrfs）、
  成员磁盘与挂载点，输入 `CREATE` 确认。
- 创建会**格式化所选磁盘**，操作前请确认数据已备份。
- 支持挂载/卸载、扩容（追加磁盘 + grow + resize）、删除（输入 `DELETE`，可选 wipefs）。

### 挂载点

展示设备、文件系统、容量、已用与百分比。

## 9. 网络与共享（管理员）

### 网络接口

- 显示 MAC、状态、MTU、IP、模式。
- 编辑可切换 DHCP / 静态 IP，设置地址、网关、DNS。
- 应用需要输入 `APPLY`；修改网络可能导致当前连接中断，建议在本地/带外管理下操作。

### 共享目录

- 内置 `users`、`photos`、`movies` 三个 SMB 共享。
- 可新增共享：名称、绝对路径（必须在 `/data` 下）、协议（SMB/NFS）、只读、
  允许用户（如 `@users`）、是否允许访客。
- 保存后自动渲染 `smb.conf` / `/etc/exports` 并 reload；失败会在界面显示警告。
- 「应用共享配置」可强制重新应用。

### 端口

列出 TCP/UDP 监听地址、端口、进程与 PID，用于排查冲突。

### DDNS 与 DNS

- 支持 DuckDNS、Cloudflare（API Token + 域名）、自定义 URL 模板。
- 可设置更新间隔、立即更新，显示上次 IP/时间/错误。
- DNS 支持多个服务器，保存后写入 `/etc/resolv.conf`。

## 10. 应用中心（管理员）

内置 qBittorrent、Jellyfin、Nextcloud、AdGuard Home、Alist、Syncthing、Uptime Kuma。

- 「安装」会拉取镜像并创建 Compose 项目，数据保存在
  `/data/docker/compose/<slug>/`。
- 可启动、停止、卸载；卸载保留数据目录，便于重新安装。
- Docker 不可用时安装会失败并提示。

## 11. 系统监控

- **实时卡片**：CPU、内存、网络、磁盘读写、运行时间、负载、进程数。
- **历史曲线**：CPU/内存、网络；SSE 实时推送，断线自动降级轮询。
- **温度**：来自 hwmon/thermal，未检测到时显示提示。
- **进程**：按 CPU 排序，支持搜索、结束进程（可强制 SIGKILL，仅管理员）。
- 开发模式下所有数值为模拟数据，页面顶部会提示。

## 12. 日志与审计（管理员）

- **审计日志**：时间、用户、类别、操作、对象、详情、IP、结果；按类别/用户/时间筛选。
- **登录日志**：成功/失败、IP、原因。
- **系统日志**：系统事件 + `journalctl` 最近输出。
- **销毁日志**（专业版）：触发原因、方式、状态、详情。
- **导出 CSV**：按当前筛选条件导出，UTF-8 BOM，Excel 可直接打开。

## 13. 系统设置（管理员）

### 个性化（管理员）

- 窗口圆角：0–24px，0 为方方正正的窗口。
- 自定义壁纸：支持 JPG / PNG / WebP（≤25MB），可勾选同时用于登录页。
- 保存后立即应用到桌面窗口；登录页会读取同一张壁纸。
- 侧边栏显示/隐藏与宽度可在任务栏「布局」菜单或各页面按钮控制。

### 通用

- 系统名称与官网标识（登录页/侧边栏）。
- 界面语言、深色/浅色主题。
- 系统信息、可选组件能力（Samba/NFS/Docker/ffmpeg/smartctl/cryptsetup/mdadm/nft）。
- 系统更新：检查、一键升级（后台任务 + 进度）。

### 账户安全

- 修改自己的密码，注销其他会话。
- 启用/关闭双重认证（2FA）：扫描二维码或手动输入密钥，验证 6 位码。
- 查看登录会话（IP/UA/最近活动），逐个注销。

### 安全策略

- 登录失败锁定：阈值、统计窗口、锁定时长。
- 递增延迟：起始次数、基础延迟、最大延迟。
- HTTPS：生成自签名证书，重启服务后生效。
- 防火墙：nftables 规则可编辑；应用后 120 秒内需点击「保留规则」，否则自动回滚。

### 通知

支持邮件（SMTP）、Telegram、Bark、Server酱；保存后可发送测试通知。
敏感字段在读取时以 `__keep__` 脱敏，留空即保留原值。

### 备份恢复

- 下载配置备份（数据库、密钥、设置；不含媒体文件）。
- 恢复需要上传备份并输入 `RESTORE`，完成后重启服务。
- 可设置自动备份开关、保留份数。

### 数据销毁（专业版）

- 启用自动销毁、阈值、时间窗口、方式（LUKS 密钥销毁 / 覆写 / 删除）、
  回退方式、静默、通知管理员。
- 加密卷管理：为每个用户创建/解锁/锁定 LUKS 卷；创建时会把现有文件迁入加密卷。
- 手动销毁：输入用户名确认后异步执行，进度可在任务中查看。
- 安全提示：销毁不可恢复；请先确认备份与策略。

### 关于

版本、版本类型、开源协议、Debian 基础版本与官网。

## 14. 普通版 / 专业版差异速查

| 场景 | 普通版 | 专业版 |
| --- | --- | --- |
| 管理员看他人文件 | 可以（可关闭） | 不可以 |
| 用户文件隔离 | 否 | 是 |
| 查看他人配额 | 可以 | 不可以 |
| 删除用户 | 立即 | 30 天冷静期 |
| 销毁策略 | 无 | 有 |
| 全盘加密 | 手动/可选 | 安装时默认 |

## 15. 常见问题

**忘记管理员密码？**
使用 `/root/privacyos-initial-password`（若未修改）；否则停止服务后删除
`/etc/privacyos/privacyos.db` 会重新种子管理员，但会丢失面板配置与用户索引。

**上传失败？**
检查配额、磁盘空间、文件大小（单次上传上限 64 GB）、网络中断。

**SMB 无法登录？**
确认 Samba 已安装（`systemctl status smbd`）、用户有 Samba 密码（管理员重置密码会同步）、
防火墙开放 445。

**视频无法播放？**
浏览器不支持该容器/编码。尝试 MP4(H.264/AAC)，或安装 Jellyfin。

**如何扩容？**
存储管理 → 存储池 → 扩容，选择新磁盘；或在文件系统中添加挂载点并迁移数据。

**如何升级 PrivacyOS？**
替换 `/opt/privacyos/bin/privacyos-server` 与 `/opt/privacyos/web` 后重启服务；
数据库迁移会自动执行。升级前请备份 `/etc/privacyos`。
